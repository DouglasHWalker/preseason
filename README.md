# Preseason

A 12-week preseason football training app: strength, HIIT circuits, 4×4 VO2 max intervals, left-foot drills for a wing back, Zone 2 and yoga. It runs in the browser, installs to your home screen and works offline. All data stays on your phone.

## Put it on GitHub Pages

1. Create a new public repository on GitHub (for example `preseason`).
2. Upload every file in this folder to the root of the repository: `index.html`, `sw.js`, `manifest.webmanifest`, the four `.png` icons and this README.
3. In the repository go to **Settings → Pages**, set **Source** to "Deploy from a branch", choose `main` and `/ (root)`, then **Save**.
4. After a minute the site is live at `https://<your-username>.github.io/preseason/`.

## Install on iPhone

Open the link in **Safari**, tap **Share → Add to Home Screen**, then always open it from the new icon. Your data lives in that home-screen app.

## Updating

Upload the new files over the old ones. The app picks up the new version the next time it's opened online, and shows an "Update" button when it's ready.

## Backups

More → Backup & restore → Export backup. Do it weekly. Backups can include your photos and GIFs.
